# 4. 初回AI画像解析

AI画像解析を初めて利用する直前に表示します。

## Title

**写真をAIで解析します**

## Body

Re:Memoryは、写真から出来事の候補を見つけるため、解析用に加工した画像を外部AIサービスへ送信する場合があります。

AIの結果は推測です。
あなたが確認した情報とは区別して扱います。

AI処理に不要な正確なGPS情報やパスワードは送信しないことを基本とします。

## Detail

**AI利用について**

## Actions

Secondary: **今回は使わない**

Primary: **同意して解析する**

# 5. Memory Gap 初回説明

最初のMemory Gapを表示する前、または最初のGapカード内で説明します。

## Title

**少しだけ教えてください**

## Body

写真だけでは分からない大切な文脈があります。

Re:Memoryが候補を絞るので、合っているか確認してください。

正解が分からなければ、あと回しでも大丈夫です。

# 6. Memory Map 初回説明

Mapを初めて開いたとき、位置情報のOS許可を求める**前**に表示します。

## Title

**場所から、Memoryをひらく**

## Body

Memory Mapは、自分が体験した場所が少しずつ開いていく地図です。

Re:Memoryは、正確な移動経路を記録するための地図ではありません。

現在地を使う場合、正確な位置を端末上で粗い地域・位置セルへ変換し、粗い情報だけを保存することを基本とします。

## Actions

Secondary: **今は使わない**

Primary: **現在地を使う**

## Detail link

**位置情報の利用について**

# 7. 位置情報 Permission Denied

## Title

**位置情報は許可されていません**

## Body

現在地を使わなくても、保存済みのMemoryを見たり検索したりできます。

Memory Mapで現在地を使いたい場合は、ブラウザまたは端末の設定から位置情報を許可してください。

## Actions

Primary: **保存済みの地図を見る**

Secondary: **あとで**

---

# 8. 空のMemory Map

## Title

**まだ地図にMemoryがありません**

## Body

写真や出来事に場所の手がかりが増えると、あなたのMemory Mapが少しずつ開いていきます。

現在地を使うこともできますが、位置情報の利用は任意です。

## Actions

Primary: **現在地からひらく**

Secondary: **写真を追加する**

# 9. AI推測ラベル

UI内でAI推測と確認済み情報を区別するための短い表記です。

### AI inference

**AIの推測**

補足:
> 写真などのEvidenceからAIが推測した内容です。

### User confirmed

**あなたが確認済み**

補足:
> あなた自身が確認・訂正した内容です。

### Deterministic / Evidence

**記録から確認**

補足:
> 日時など、保存された記録から確認できる情報です。

### Unknown

**まだ分かりません**

補足:
> Re:Memoryには、この内容を判断できる十分な根拠がありません。

# 10. 削除確認

## Memory削除

### Title

**このMemoryを削除しますか？**

### Body

このMemoryと関連するRe:Memory上の情報を削除します。
この操作は元に戻せない場合があります。

### Actions

Secondary: **キャンセル**

Destructive: **Memoryを削除**

---

## 探索済みMapの削除

### Title

**探索した地図を消去しますか？**

### Body

Memory Mapの探索情報を削除します。
保存済みのMemoryそのものは削除されません。

### Actions

Secondary: **キャンセル**

Destructive: **地図を消去**

---

## アカウント削除

### Title

**Re:Memoryのアカウントを削除しますか？**

### Body

アカウントと対象のユーザーデータを削除します。
この操作は取り消せません。

必要なデータがある場合は、削除前にデータを書き出してください。

### Actions

Secondary: **キャンセル**

Destructive: **アカウントを削除**

# 11. UI実装時の原則

1. 利用規約とプライバシーポリシーへの基本同意は新規登録時に取得する。
2. AI画像解析の説明は、最初にAIへ画像を送る直前に行う。
3. 位置情報の説明は、ブラウザ / OSのPermission Dialogを出す前に行う。
4. チュートリアルを見ないとログインできない設計にはしない。
5. 長文規約をチュートリアルへ詰め込まない。
6. 「同意する」ボタンだけでなく「今回は使わない」を用意する機能は、可能な限り機能単位で提供する。
7. AI推測・ユーザー確認済み・記録から確認できる情報を視覚的にも区別する。
8. Location OFF / AI OFFでも、利用可能な既存機能まで不必要に無効化しない。
