## Product principles

Re:Memory の文章は、以下のプロダクト原則と一致させます。

1. AIの推測と、ユーザーが確認した事実を区別する。
2. 分からないことを、AIが無理に事実化しない。
3. 写真・位置情報・記憶は必要最小限の範囲で処理する。
4. 正確なGPS軌跡を通常のMemoryデータとして保存しない。
5. AI解析・位置情報など、目的が異なる機能は必要なタイミングで個別に説明する。
6. 削除・訂正・設定変更など、ユーザー自身がデータを管理できることを明確にする。
