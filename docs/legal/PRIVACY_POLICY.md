# Re:Memory プライバシーポリシー

制定日: 2026-08-14

Re:Memory開発チーム（以下「運営者」といいます。）は、Re:Memory（以下「本サービス」といいます。）におけるユーザー情報を、以下の方針に基づいて取り扱います。

## 1. 基本方針

Re:Memoryは、写真や出来事を整理し、ユーザー自身が過去を振り返ることを支援するサービスです。

そのため、写真、位置に関する情報、AIによる推測、ユーザーによる確認・訂正など、個人の生活に深く関係し得る情報を扱います。

運営者は、取得する情報と利用目的をできる限り明確にし、目的に必要な範囲で取り扱い、安全管理とユーザー自身による管理を重視します。

## 2. 取得または処理する情報

本サービスでは、機能提供のため、以下の情報を取得または処理する場合があります。

### アカウント情報

- メールアドレス
- 認証に必要な情報
- アカウント識別子
- アカウント設定

### ユーザーが登録する情報

- 写真
- 写真に含まれるメタデータ
- ユーザーが入力したMemory情報
- ユーザーによる確認・訂正内容
- 検索内容
- ユーザーが明示的に送信したフィードバック

### 本サービスが生成する情報

- Temporal Sequence
- Event
- Evidence
- Claim
- Memory
- AIによる推測候補
- Memory Gap
- Context Completenessその他、Memoryの整理・検索に必要な内部情報

### 位置に関する情報

- 写真に含まれる位置に関する情報
- ユーザーが明示的に許可した場合の端末位置情報
- 正確な位置から変換した粗い地域情報または位置セル
- ユーザーが入力または確認した場所に関する情報

### 技術情報

- セキュリティおよび障害解析に必要なログ
- リクエスト情報
- 不正利用防止に必要な情報
- サービスの安定運用に必要な技術情報

## 3. 利用目的

取得または処理した情報は、以下の目的で利用します。

- 本サービスの提供、維持および改善
- 写真やメタデータから出来事を整理するため
- Memoryの作成、表示、確認、訂正および削除のため
- ユーザーが過去の出来事を検索・振り返ることを支援するため
- AIによる画像解析、文脈推定、候補生成および検索支援のため
- AIによる推測についてユーザーへ確認を求めるため
- Memory Map等、場所からMemoryを振り返る機能を提供するため
- ユーザーが明示的に有効化した学習・フィードバック機能を提供するため
- 不正利用、不正アクセスその他のセキュリティ上の問題を防止・調査するため
- 障害の調査、復旧およびサービス品質向上のため
- ユーザーからの問い合わせに対応するため

利用目的を大きく変更する場合は、必要に応じて本ポリシーまたはサービス内表示を更新し、適切な方法で案内します。

## 4. 写真の取扱い

アップロードされた写真は、ユーザーごとに分離された非公開領域で取り扱うことを基本とします。

AI解析を行う場合、必要に応じて画像サイズを縮小し、解析に不要なメタデータを除去した派生画像を作成して利用します。

AI処理に不要な正確な位置情報その他の情報を、AIへの入力へ含めないことを基本方針とします。

ただし、ユーザーがアップロードした元画像自体にEXIF位置情報その他のメタデータが含まれている場合、元画像ファイル内には当該情報が存在する可能性があります。

## 5. 位置情報の取扱い

Re:Memoryは、ユーザーの正確な移動経路を常時記録することを目的としたサービスではありません。

Memory Map等で端末位置情報を使用する場合は、ユーザーへの説明と操作を経て位置情報へのアクセスを求めます。

設計上可能な場合、以下の処理を基本とします。

```text
端末で一時的に現在位置を取得
↓
端末上で粗い地域または位置セルへ変換
↓
正確な緯度・経度を通常のアプリ状態から破棄
↓
粗い情報のみサーバーへ送信・保存
```

正確なGPS軌跡、秒単位の移動履歴、常時バックグラウンド追跡等を通常のMemory Mapデータとして保存しないことを基本方針とします。

位置情報の詳細は「位置情報の利用について」に定めます。

## 6. AIサービスの利用

本サービスの一部機能では、外部のAIサービス、AI APIまたはAPIゲートウェイを利用する場合があります。

外部AIへ情報を送信する場合は、機能提供に必要な範囲へ入力を限定するよう努めます。

送信される可能性がある情報には、以下が含まれます。

- 解析用に加工された画像
- Memory生成に必要な文脈
- Evidenceの一部
- 検索・候補生成に必要な情報

パスワード、サービス用秘密鍵、AI処理に不要な正確なGPS情報等をAIへ送信しないことを基本とします。

利用するAI提供者、処理場所その他ユーザーの判断に重要な事項については、正式公開時の実構成に合わせて本ポリシーまたはサービス内表示で明示します。

AI利用の詳細は「AI利用について」に定めます。

## 7. 第三者提供・外部委託

運営者は、法令で認められる場合を除き、本人の同意なく個人データを第三者へ提供しません。

本サービスの提供に必要な範囲で、クラウドホスティング、データベース、ストレージ、メール配信、AI処理その他の業務を外部事業者へ委託する場合があります。

委託先については、取り扱う情報の性質に応じて適切な管理に努めます。

外国にある事業者への提供または委託に関して追加の説明・同意が必要となる場合は、正式公開時の実構成に応じて必要な対応を行います。

## 8. 安全管理

運営者は、ユーザーデータへの不正アクセス、漏えい、改ざん、消失等を防ぐため、合理的な安全管理措置を講じます。

これには、認証、アクセス制御、非公開ストレージ、通信の保護、権限制御、入力検証、秘密情報のサーバー側管理等を含みます。

## 9. ユーザーによる管理

ユーザーは、本サービスが提供する機能を通じて、可能な範囲で以下を行うことができます。

- Memoryの確認
- AIによる推測の確認・訂正
- Memoryの削除
- Privacy / AI設定の変更
- 明示的な検索学習の有効化・無効化
- 対応しているデータの書き出し
- アカウント削除

特定の機能を無効化した場合のデータ削除・保持については、その機能の説明または設定画面で明示します。

## 10. 保存期間

ユーザーデータは、本サービスを提供するために必要な期間保存します。

ユーザーが対象データまたはアカウントを削除した場合、法令、セキュリティ、不正利用防止等のため保存が必要な情報を除き、対象データの削除処理を行います。

バックアップその他のシステムから完全に消去されるまで、合理的な期間を要する場合があります。

具体的な保存期間を定めるデータについては、正式公開時の実運用に合わせて明示します。

## 11. 開示・訂正・削除等

ユーザー本人から、自身の情報について開示、訂正、利用停止、削除その他の請求を受けた場合は、適用される法令および本人確認に必要な手続に従って対応します。

本サービス内でユーザー自身が操作できる項目については、可能な限りサービス内機能から管理できるようにします。

## 12. 本ポリシーの変更

サービス内容、利用する技術、提供地域、法令その他の事情の変更に応じ、本ポリシーを変更する場合があります。

重要な変更については、本サービス上その他適切な方法で通知します。

## 13. お問い合わせ

本ポリシーに関する問い合わせ先は、正式公開時に本サービス内または公式案内に明示します。
