# Re:Memory 位置情報の利用について

最終更新: 2026-08-14

## Re:Memoryは、あなたの行動を監視するためのアプリではありません

位置に関する情報は、写真やMemoryを「場所から思い出す」ために利用します。

Memory Mapでは、行ったことのない場所、通った場所、体験した場所、Memoryがある場所を区別し、自分の人生で触れた場所が少しずつ開いていくPersonal Memory Mapを作ることを目指します。

## 現在地を使うタイミング

Re:Memoryは、現在地を必要とする機能をユーザーが選択したときに、位置情報へのアクセスを求めます。

ページを開いたことだけを理由に、説明なく現在地の取得を開始しないことを基本とします。

## 正確な位置をそのまま残さない

Memory Mapで現在地を利用する場合、設計上可能な範囲で次の処理を行います。

```text
正確な現在位置を端末で一時的に取得
↓
端末上で粗い地域・位置セルへ変換
↓
正確な緯度・経度を通常のアプリ状態から破棄
↓
粗い位置情報だけをサーバーへ送信・保存
```

Memory Mapの通常データとして、正確な緯度・経度そのものを保存しないことを基本方針とします。

## 保存しないことを基本とする情報

- 正確なGPS軌跡
- 秒単位の位置履歴
- 常時の移動経路
- Web版での常時バックグラウンド追跡
- AI処理に不要な正確なGPS情報
- 位置の詳細軌跡を使った広告目的のプロファイリング

## 写真に含まれる位置情報

写真自体にEXIF位置情報が含まれている場合があります。

Re:Memoryは、Memory生成に必要な範囲で写真のメタデータを読み取る場合がありますが、通常のMemory情報では必要以上に細かい位置を保持しないことを基本とします。

AI画像解析を行う場合は、解析に不要なメタデータを除去した派生画像を利用することを基本とします。

ただし、元画像ファイルそのものにEXIF位置情報が含まれている場合、非公開で保存された元画像内には当該情報が残る可能性があります。

## Memory Mapの状態

Memory Mapでは、概念上次の状態を扱います。

```text
Unknown
まだ訪問を示すEvidenceなし

Passed
近くを通ったことを示す粗いEvidenceあり

Experienced
写真・滞在・出来事等のEvidenceあり

Memory
実際のMemoryと結び付いている
```

近くを通っただけで、その場所を訪問したMemoryとして自動確定しません。

## 位置情報を許可しなくても使えます

位置情報の利用は任意です。

位置情報を許可しない場合でも、すでに保存されているMemoryの閲覧、検索、確認・訂正など、位置情報を必要としない機能を利用できることを基本とします。

## 位置情報を削除する

Memory Mapで保存した探索情報については、ユーザーが削除できる機能を提供することを基本とします。

探索情報を削除しても、別途保存されているMemoryそのものを自動的に削除しない設計とします。

アカウントを削除した場合は、法令上またはセキュリティ上保存が必要な情報を除き、アカウントに紐づくMemory Mapデータも削除対象とします。

## 将来のバックグラウンド位置情報

Web版では、常時バックグラウンド位置取得を前提としません。

将来、ネイティブアプリ等でバックグラウンド位置情報を利用する機能を検討する場合は、現在の位置情報利用とは別の機能として、目的、取得範囲、保存方法、停止方法を改めて説明し、必要な許可を取得します。
